# Bowing Motion Videos

This repository contains demonstration videos of the bowing motions used in the following study:

Osugi, T., & Kawahara, J. I. (2026). Effect of bowing on facial attractiveness of other races. *Japanese Psychological Research*. https://doi.org/10.1111/jpr.70051

## Videos

* [Long bow](long-bowing.mp4)
* [Short bow](short-bowing.mp4)

The videos show simulations of long and short bows performed by 3D computer-generated models.
